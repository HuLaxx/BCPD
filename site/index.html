03 / THE RESEARCH QUESTION

Does the pattern travel?

A single well-tuned chart can be persuasive for the wrong reasons. This study asks whether candidate structural breaks are robust across national equity markets, cryptocurrency returns and alternate model assumptions. The sensitivity panel repeats the same Bayesian recursion under three hazard settings and three observation-variance scales.

Equity trading days and 24/7 crypto markets cannot be aligned one-to-one. Using each market's last observed close within a common Sunday–Saturday UTC window avoids inventing missing daily returns.

04 / METHOD & CAUTION

A retrospective model, not a crystal ball.

We compute weekly percentage log returns, then apply a Gaussian mean-shift Bayesian online change-point recursion. The fixed observation variance is estimated from each full sample, so these analyses are retrospective and must not be described as strictly ex-ante forecasting.

Consensus measures how frequently nearby peaks appear among nine model configurations; it is not a statistically calibrated confidence probability or an accuracy score. For a dissertation-grade result, add reference event labels, alternative change-point models, sample splits and archived input data.
